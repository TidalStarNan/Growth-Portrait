# 智育成长画像平台

面向师范生的**过程性成长记录与质性反馈**平台。三端角色：学生端、教师管理端、院校管理端。

> 项目代号「智育」仅内部使用。对外正式名称：**师范生创新成长记录与反馈中心**。
> 原因：「智育」在教研语境中特指五育之一，与本平台的「创新能力」语义不符，正式场合易被误解。

## 立即预览

**双击 `index.html` 即可运行**，无需安装、无需启动服务、无需联网。

这是一个**单页应用**：所有页面在同一个文档内通过 hash 路由切换，不整页重载，没有白屏闪烁。

| 入口 | 地址 |
|---|---|
| 启动页 | `index.html` |
| 页面导航（推荐） | `index.html#/preview` |
| 学生端 | `index.html#/student/home` |
| 教师端 | `index.html#/teacher/home` |
| 院校端 | `index.html#/admin/home` |

## 三条不可让渡的产品红线

1. **不打分** —— 全系统不设分数字段、不录入量化分数、不做单一综合评分。
2. **不排名** —— 不展示学生个人排名，群体统计只做班级/全院聚合分析。
3. **不对接综测** —— 档案材料仅作育人参考，不自动计入综测加分，评奖评优沿用学校原有制度。

## 目录结构

```
智育成长画像平台/
├── index.html            唯一入口（应用壳，只有 #app 容器）
├── assets/
│   ├── css/style.css     设计令牌 + 全部组件样式
│   └── js/
│       ├── data.js       mock 数据（学生/材料/标签/研判/资源）
│       ├── views.js      23 个视图模板 + 路由表
│       ├── ui.js         图标、导航、组件、手写 SVG 图表、hash 路由
│       └── pages.js      各页面渲染逻辑与交互
├── docs/                 需求文档
└── README.md
```

**改内容去哪：** 改页面的静态结构 → `views.js`；改数据 → `data.js`；改交互逻辑 → `pages.js`；改样式 → `style.css`。

> `views.js` 里是紧凑的单行 JSON 模板。如果要大改页面结构，建议在编辑器里格式化后再改。

## 视觉与技术说明

**视觉**：沿用「班级助理」项目的 Apple HIG 语言 —— 大圆角、胶囊控件、毛玻璃导航、
轻阴影、`cubic-bezier(.32,.72,0,1)` 缓动；配色为**校园蓝 + 米白**（`#3e6ba6` / `#faf7f1`），
标题用宋体体现书卷气，正文用系统黑体。

**技术**：零依赖、零构建。
- 单页 hash 路由，切换只替换 `#app` 内容，不重载、不闪烁
- 图标全部内联 SVG，无图标库
- 图表（雷达、条形、堆叠条、折线、环形）全部手写 SVG，无 ECharts
- 无 webfont、无 CDN，断网可用
- 状态为前端 mock，刷新即恢复初始演示数据

## 演示提示

1. 从 `index.html#/preview` 进入，22 个页面一目了然。
2. 学生端画像页是核心：**雷达图上没有任何数字**，讲「证据充分程度」而不是「分数」。
3. 教师端「多元研判与反馈输出」页是「禁止量化」的落地证据，停 20 秒讲「零个数字输入框」。
4. 群体统计页切到 2 班（6 人）会触发「样本量不足」提示，这是隐私设计的直接证据。
